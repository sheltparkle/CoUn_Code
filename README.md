## 📋 Reproduction Process
### 1. Parameter Configuration
Modify the global parameters in `CoUn_Utils.py` according to your local environment:
- `DATASET_ROOT`: Path to save CIFAR-10 dataset (will be downloaded automatically if not exists)
- `DEVICE`: Training device (recommend `cuda` for GPU acceleration)
- `SAVE_ORIGINAL_PATH`: Path to save the trained original ResNet18 model
- Training hyperparameters (batch size, learning rate, epochs, etc.)
- CoUn core parameters (temperature coefficient `TAU`, contrastive loss weight `LAMBDA`, forget class index, etc.)

### 2. Train Original Model
Run `Original_Model.py` to train the ResNet18 model on full CIFAR-10 dataset (this model serves as the base model for unlearning):
```bash
python Original_Model.py
```
The best-performing original model will be saved to the path specified by `SAVE_ORIGINAL_PATH`.

### 3. Run CoUn Main Training
Run `CoUn_Main.py` to perform machine unlearning training (only uses retained data `Dr`, no access to forgotten data `Du`):
```bash
python CoUn_Main.py
```
Key features of the training process:
- Automatically filter out the forget class from the training set to construct retained data `Dr`
- Support custom sample number per non-forget class in `Dr` (modify `PER_CLASS_SAMPLES` in `CoUn_Main.py`)
- Joint training with CE loss (preserve model performance) and InfoNCE loss (realize unlearning)
- Save the optimal CoUn model based on total loss

### 4. Test Unlearning Effect
Run `Test.py` to evaluate the unlearning performance:
```bash
python Test.py
```
The test will output:
- Forgetting Accuracy (FA): Accuracy on the forget class (lower = better unlearning effect)
- Retention Accuracy (RA): Accuracy on non-forget classes (higher = better performance preservation)
- Overall Test Accuracy: Global accuracy of the model
- Unlearning Accuracy (UA): Unlearning effectiveness metric (1 - FA/100, higher = better)
- Layer-wise weight difference between original model and CoUn model (optional)
